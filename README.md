# Evidence-Driven Content Assembly

把真实经历或可信来源装配成可审计的视频/图文生产包，保留语音思路、资料清单、大纲、Demo、草稿和拍摄清单。

## 内容

- `SKILL.md`：Skill 指令
- `test-prompts.json`：6 条路由测试题
- `test-results.md`：历史测试记录

核心原则：事实有来源，观点有标注，中间产物可检查；不支持洗稿、无来源内容或自动发布。

验证记录：V1/V2/V3 通过；历史盲测 6/6。历史测试不代表内容传播效果保证。
