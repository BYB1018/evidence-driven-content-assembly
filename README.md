# Evidence-Driven Content Assembly

## 中文

把真实经历或可信来源装配成可审计的视频/图文生产包，保留语音思路、资料清单、大纲、Demo、草稿和拍摄清单。

核心原则：事实有来源，观点有标注，中间产物可检查；不支持洗稿、无来源内容或自动发布。

## English

Assemble real experiences or credible sources into an auditable video or written-content production package, preserving voice notes, source lists, outlines, demos, drafts, and shot lists.

Core principle: source facts, label opinions, and keep intermediate artifacts reviewable. This Skill does not support plagiarism, unsourced content, or automatic publishing.
